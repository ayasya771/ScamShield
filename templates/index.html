    How does ScamShield work?

    ScamShield uses naive Bayes, a classic machine-learning method for sorting text. During training it reads hundreds of messages already labelled scam or genuine and learns how often each word, phrase and clue (a link, a money amount, a number to call) shows up in each group.

    When you paste a new message it adds up that evidence to estimate the probability that the message is a scam — the same maths a spam filter uses. Because every word carries its own weight, the model can show you which words tipped the balance.

    It is a learning aid, not a guarantee. Scammers change tactics constantly, so treat a “genuine” result as “no obvious red flags” rather than a promise of safety. When money or codes are involved, always check with the organisation directly.
